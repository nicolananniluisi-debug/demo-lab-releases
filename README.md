# Demo Lab: instaladores

Este repositório só guarda os instaladores do **Demo Lab**, o app que analisa demos de CS2. O código não fica aqui.

**Para instalar:** abra a [última versão](https://github.com/nicolananniluisi-debug/demo-lab-releases/releases/latest) e baixe o `Demo-Lab-Setup-X.Y.Z.exe`. Funciona no Windows 10 e 11 de 64 bits e não pede senha de administrador.

Sem certificado: no aviso do SmartScreen, clique em "Mais informações" e depois em "Executar assim mesmo".

**Atualizações:** da 0.3.5 em diante, o app procura a versão nova sozinho a partir daqui, baixa sem atrapalhar e instala quando você reiniciar ou fechar. Suas demos, desenhos e chaves ficam.
